# ACE7pro 风扇助手 0.1.0-pilot

本地实验首版。目标：OnePlus PMS110 / OP64F1L1，Android17，已核对的OplusExSystemService APK哈希见FanHook.java。不是通用风扇控制工具。

## 已实现
- 原生App，温度、RPM和档位分图，真实时间轴、缺测断开，CSV导出。
- 息屏、有线充电中、原厂自动模式与允许开关成立时，候选层按电池温度增强；白名单允许解除锁屏快充12档软件上限。
- `i9.h.q()`候选层Hook，保留后续噪声、使能、手柄、控制器和底层保护；不直接写sysfs，不伪装温度，不改充电/关机保护。
- 曲线初值：33/35/37/39/41°C对应6/10/14/18/20需求档；降档迟滞1°C并保持30秒。需求0表示不额外增风，不强制压低原厂需求。这是工程初值，不是安全温度边界。
- 明确区分Hook遥测、App自身观测和Root只读预览，不把监测说成接管成功。

## 安装与激活
1. 安装APK后，在LSPosed的模块列表中启用“ACE7pro 风扇助手”。
2. 只勾选 `com.oplus.exsystemservice`（扩展系统服务），不要勾选系统框架/system_server或其他应用。
3. 正常重启手机，让常驻目标进程加载模块。本包不自动杀系统服务或重启。
4. 打开App确认出现“已注入”；功能开关为开且条件满足时才显示接管。再连接有线充电并息屏。

LSPosed当前若关闭开发者模式，其CLI不提供启用/作用域控制；不要通过修改配置数据库绕过。也可以由用户打开开发者模式后，使用该版本官方lspctl检查与配置，随后仍需目标进程重新加载。

## 数据说明
- RPM为节点反馈，不用speed、档位或rpm_table推算冒充。0是零读数，并不单独证明停转或故障。
- driver/effective/控制器请求/模块候选分开显示；驱动可能降额，不能承诺请求20就实际20。
- App观测只有前台采样，不接管；目标进程UID1000的传感器权限尚待激活后验证。读不到就显示未知/使用明确标注的电池广播回退，不提权或放宽权限。
- 采样名义每5秒，无持续WakeLock；深度休眠中可能延迟，图表会标记间断。
- 私有数据库环形上限10000点、最近7天，界面最多4000点；无网络权限、无云上传。

## 验证边界
已做Java编译、D8、XML/资源打包、v3签名、ZIP/对齐和ChargeCurve边界/迟滞/延时/失效/仅增强测试。实际已安装不等于LSPosed已经启用，实际注入与息屏调速效果需重启后核验。

Root只读预览是由Eta明确发起的有界临时诊断，最多10分钟，仅读取温度与风扇反馈并写入本App历史；不控制风扇，不是Hook生效证据。APK中的PreviewMain是诊断入口，不会自行运行，不是常驻Root服务。该设备app_process预览尝试曾被系统终止，实际可用预览改用只读系统Shell；主模块App与Hook不依赖该诊断入口。

## 回退
在App关闭增强，已注入时会安排原厂重算；或在LSPosed禁用本模块后正常重启。不删除/停用原厂风扇服务，不关闭SELinux，不改温控节点。若出现服务不稳定，优先禁用本模块并重启。

## 构建
Linux ARM64轻量构建：Java25编译为Java8，D8与编译类库Android35；Debian AAPT1只用Android28资源JAR打包（不能解析35的新资源表），targetSdk35/min28保持不变。`build.sh`说明工具位置。
Xposed API82仅compileOnly，运行要求LSPosed/API93+。不在APK内打入Xposed API或Android类库。
签名密钥仅保留在本地私有build-tools/keys，不随源码ZIP、APK或公共说明导出。未来更新需同一密钥签名。源码包不含工具链下载、第三方固件工件、数据库或密钥。
