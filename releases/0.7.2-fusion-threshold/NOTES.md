# 0.7.2-fusion-threshold

## 新增

- 日用增强改为按融合阈值双向启停：放电、日用已开启且确认原厂普通自动目标时，融合温度高于设定值可从原厂 0 档起转，低于或等于设定值在下一次采样请求停转。此前阈值上方 0 档与阈值下方非 0 档都原样放过。
- 概览区分融合温度目标、原厂控制请求与驱动有效档位，并标出本次实际参与融合的通道；权重为 0 的传感器不参与融合，但仍参与异常高温检查。
- 设置页更新日用文案与停转反馈，说明阈值两侧的实际行为与「保存参数」不等于「已启用」。

## 修复

- Hook `0.6.3-daily-threshold`：候选只在本轮确认原厂 `Common` 普通自动目标后才双向改档，避免在降噪、手柄、故障等受保护场景抢控制；系统或独立传感器热状态异常时整轮交还原厂。
- 采样过期、任务栈切换、充电或停放电条件变化时撤销日用请求，不再保留过期候选；停转不再依赖额外的 30 秒迟滞。
- 保留已保存的配置、数据格式、四路融合与充电策略；覆盖安装不会开启或改变已有日用设置。
