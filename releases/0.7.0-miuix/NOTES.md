# 0.7.0-miuix

## 新增

- 使用 Compose Miuix 重做概览、趋势、设置和编辑器。概览直接显示融合温度、四路传感器温度和有效档位；运行状态只占一行小字。
- 日用增强独立开关、介入温度、最低增强档位、四路权重编辑。保存前预览有效占比与融合温度，过期配置不会覆盖较新版本。

## 修复

- 不把原厂控制请求当成驱动档位；缺测留空；趋势按实际时间绘制并在缺口处断线。原始传感器曲线和诊断改为按需展开。
- 充电模式仍走原开关及原控制策略；新日用设置不改变充电规则。原厂给零档时不强制起转。

## 验证与限制

- 复用之前的签名证书；无新增 Android 权限，作用域仍只限 `com.oplus.exsystemservice`。最终离线检查与设备状态见 [状态快照](../../knowledge/STATE.md)。
- 前端可独立只读观测；已保存的设置、Hook 已读取的配置、驱动档位分别呈现。静态编译与签名验证不等于手机上已加载或风扇效果已验证。
