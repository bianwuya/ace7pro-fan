# ACE7pro 风扇助手 0.2.0-miuix

## 本版：前端重构 + 移除转速读取

- 前端按 Miuix 的视觉语言重做：大标题、24dp 圆角实色卡片、克制的蓝色强调、概览／趋势／设置三页与底部导航。
- 深浅主题可跟随系统或强制指定；分段控件、开关、弹窗全部自绘并统一配色，不再出现深色界面黑字下拉框。
- **完整移除风扇转速（RPM）读取与展示**：该节点在本固件读数不可靠，App 不再采集、不再画、不再导出，也不用 speed、占空比或档位换算冒充转速。
- 温度曲线与档位曲线拆成两张独立卡片，图例在绘图区外，刻度取整，缺测断线。
- 控制策略、温度阈值、Hook 逻辑未改动。

## 界面

- 概览：当前阶段（息屏增强／锁屏衔接／解锁交还／保留原厂）、增强开关、电池温度、驱动有效档位、辅助温度（板级／风扇周边／充电相关）、电池温度迷你趋势。
- 趋势：15 分钟 / 30 分钟 / 本次充电；温度卡（电池、板级、风扇周边、充电相关）与档位卡（模块需求、驱动有效，可展开控制器请求与驱动设定）。
- 设置：增强开关、唤醒锁屏衔接说明、温度—档位曲线查看、主题模式、导出 CSV、模块诊断、清空历史。
- 顶部状态胶囊区分“已注入”“待重载”“未注入”“只读预览”：旧版 Hook 没有版本字段时显示“待重载”，提示需要正常重启。

## 数据与 CSV 变更

- `Telemetry` 只读 `level`、`level_eff`、`state`、`status` 与四个温度，不再访问 `/sys/class/leds/fan/rpm` 或 `speed`。
- CSV 新表头去掉 `rpm` 列，其余列不变；历史 JSON 里的旧 rpm 字段保留但不再导出，数据库不做破坏性重写。
- 档位表示控制请求，不代表实测转速；驱动可能降额，请求 20 不保证物理 20。

## 既有行为（未改动）

- 息屏、有线充电中、原厂自动模式与允许开关成立时，候选层按电池温度增强；白名单允许解除锁屏快充 12 档软件上限。
- `i9.h.q()` 候选层 Hook，保留后续噪声、使能、手柄、控制器和底层保护；不直接写 sysfs，不伪装温度，不改充电／关机保护。
- 点亮但仍停留在锁屏时延续增强；真正解锁后最多 2 秒交还原厂。
- 曲线初值：33/35/37/39/41°C 对应 6/10/14/18/20 需求档；降档迟滞 1°C 并保持 30 秒。工程初值，不是安全温度边界。

## 安装与激活

1. 安装 APK 后，在 LSPosed 的模块列表中启用“ACE7pro 风扇助手”。
2. 只勾选 `com.oplus.exsystemservice`，不要勾选系统框架／system_server 或其他应用。
3. 正常重启手机，让常驻目标进程加载模块。本包不自动杀系统服务或重启。
4. 打开 App 确认状态为“已注入”；若显示“待重载”，说明安装的 Hook 尚未被目标进程加载，重启后再看。

界面本身的改动不需要重启即可看到；Hook 版本要等目标服务重新加载。

## 数据说明

- driver／effective／控制器请求／模块候选分开显示；驱动可能降额，不能承诺请求 20 就实际 20。
- App 观测只有前台采样，不接管；读不到就显示“—”，不用 0 补值。
- 采样名义每 5 秒，无持续 WakeLock；深度休眠中可能延迟，图表会显示间断。
- 私有数据库环形上限 10000 点、最近 7 天，界面最多 4000 点；无网络权限、无云上传。

## 验证边界

已做：Java 编译、D8、XML／资源打包、v3 签名、ZIP／对齐检查、ChargeCurve 与 WakeHandoff 单元测试；APK 内 `classes.dex` 不含 `rpm` 字符串；在 1272×2772 设备上渲染核对了深浅主题的三页布局、主题弹窗与诊断弹窗。

未做：CSV 导出到系统文件选择器的实际写入、清空历史的实际写入未逐项点按验证；锁屏唤醒的物理效果仍需实机重启后复测。设计稿与单元测试都不能当作物理转速验收。

## 回退

在 App 关闭增强，已注入时会安排原厂重算；或在 LSPosed 禁用本模块后正常重启。不删除／停用原厂风扇服务，不关闭 SELinux，不改温控节点。

## 构建

Linux ARM64 轻量构建：Java25 编译为 Java8，D8 与编译类库 Android35；Debian AAPT1 只用 Android28 资源 JAR 打包，targetSdk35／min28 保持不变。Xposed API82 仅 compileOnly，运行要求 LSPosed／API93+。签名密钥仅保留在本地私有 `build-tools/keys`，不随源码 ZIP、APK 或公共说明导出。
