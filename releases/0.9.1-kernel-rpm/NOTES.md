# 0.9.1-kernel-rpm

## 新增

- 独立 Root FG 被动接收通道，直接接收原驱动真实 `FAN_RPM` 事件并回传 App；不依赖旧系统进程 Hook 的进程内缓存，不读取旧 rpm/speed/duty 节点，不用日志或目标表代替运行数据。
- 统一 KernelSU ZIP 含原签名 App/code28、完整日用阶梯驱动与固定哈希早期加载器；所有源码先落本地工作区，发布目标为 `bianwuya/ace7pro-fan`，不是 Eta 仓库。

## 修复

- 修复融合40°C以上仍固定最低10档：恢复本机原厂普通阶梯需求，按用户四路融合温度运行，10档只作为下限。升温阶梯为35/37/39/40/41/43°C→6/10/14/16/18/20档；保留阶梯降温回差，不擅自平移原表，也不声称复刻原厂ShellTemp/KP/功耗模型。
- 保留用户36°C起转、35°C及以下连续30秒停机、normal升降斜坡和所有温度/硬件保护；充电算法不改。40.597°C升温路径目标16档的回归通过。
- 转速沿用同有效档位首次有效实测保持；换档、停机、故障、调试覆盖或无效数据清除旧值，缺测不填假零。原可选Hook通道仍保留。
