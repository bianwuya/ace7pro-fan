# 0.7.3-fusion-hysteresis

## 新增

- 概览右上角「数据与诊断 → GitHub 源码与适配」，可用系统浏览器或 GitHub 应用查看源码、系统与 Root 框架兼容说明，便于提交适配反馈。未增加 App 权限，不上传诊断数据。

## 修复

- 日用风扇不再因融合温度在启动阈值旁波动而频繁启停。高于设定温度起转；起转后，降至设定值减 1°C 或更低并连续保持 30 秒才请求停转，中途回温重新计时。
- 保留原厂限档和保护，以及充电、配置、历史数据和签名身份。覆盖安装后需正常重载原厂进程，确认运行 Hook 为 `0.6.4-daily-hysteresis`。

## 验证与限制

- 自动回归覆盖阈值和停转线等值、29.999/30 秒、短暂回温、样本中断、插电、配置变化与异常热状态隔离。真实 ROM 下以同轮控制请求和驱动有效档为准，不以候选档位替代物理结果。
- 代码不扩大支持的机型、ROM 或 Root 环境；兼容范围见 [COMPATIBILITY.md](../../COMPATIBILITY.md)。
