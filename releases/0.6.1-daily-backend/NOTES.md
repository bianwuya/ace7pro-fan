# 0.6.1-daily-backend

## 新增

- 独立日用后端：电池供电、原厂自动及正常场景，配置融合温度门槛、四路权重、最低增强档；默认关闭。
- 版本化读写和只算不保存的权重预览接口，隔离于已有充电设置；见 [日用后端契约](../../knowledge/DAILY-FAN.md)。

## 修复

- 供电切换、缺测、陈旧配置或原厂限制时不会沿用日用需求，也不把充满、暂停或无线充电当作日用。
- 衔接本地及 CI 的 AAPT2/签名工具路径，不改变证书指纹校验。

## 验证与限制

- 离线验证覆盖权重、阈值、OEM 候选上限、切换/过期和 SQLite 迁移。充电模式保持既有曲线、设置与唤醒行为。
- 原厂 0 档不抬正；尚无新的 Hook 真机加载或风扇物理验收。预览图不代表前端已经实现。
