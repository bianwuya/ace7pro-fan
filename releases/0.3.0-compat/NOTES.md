# 0.3.0-compat

## 新增

- 新增“设置 → 版本兼容性”页，集中显示系统与原厂服务版本、接口档案与匹配原因、Xposed Bridge API、兼容判断依据及实测边界；框架未公开语义版本时显示未知，不拿 Manager 版本冒充。
- 新增面向固件差异的接口与关键代码匹配：保留 ACE7pro PMS110 / OP64F1L1 硬件校验，解析原厂 V3 风扇接口，并核对候选层及后续保护链的 11 个关键方法指纹；唯一签名且代码匹配才允许接入，部分混淆名称变化可识别，歧义或不匹配时拒绝接管、仅观测。
- 取消把 Android 17 / SDK 37 或原厂服务 APK 整包哈希变化作为单独的硬性拒绝条件；整包哈希仍用于标记参考固件，运行时仍须通过硬件、接口与关键代码校验。
- 将传统 Xposed 最低 API 调整为模块实际使用的 API 82，不依赖 modern libxposed 入口；补齐 API 33+ 锁屏监听器隔离加载路径。

## 修复

- 修复独立 Manager 启动/跳转失败时被误报为“未找到 LSPosed”的诊断；提供用户主动尝试寄生入口及手动进入说明，不把尝试动作当作已成功。
- 修复 30 秒空闲采样与旧 UI 20 秒新鲜度超时冲突，避免本地观测误盖掉有效注入状态；历史或跨启动回报仍不证明当前 Hook 已激活。
- 补齐 Android API 33 以下的锁屏广播注册与实时状态读取兜底，避免旧系统调用 API 33 接收器重载。

## 验证与限制

- 已记录的离线验证包括原有曲线、锁屏衔接及采样测试，22 项兼容合成检查，真实参考固件原厂 APK 的 11 处关键方法指纹与合成变体检查，以及 Java 8 编译、D8、资源/Manifest 打包、签名和对齐检查。合成变体不是其他 ROM；这些结果不证明其他固件或框架实机兼容。
- 本地交付记录显示 0.3.0-compat 已安装；截至 [状态快照](../../knowledge/STATE.md) 所记的 2026-11-03 19:21 核验时点，目标原厂服务仍加载旧 Hook `0.2.1-eco`。新 Hook 的正常重载、兼容页实机显示及增强、锁屏衔接、解锁后交还等手动功能验收仍待完成；安装包、离线构建与旧进程回报均不能替代这些验收。
- 尚无其他真实系统固件或不同框架组合的本版功能实测；接口或关键代码不匹配的设备仅观测。详细范围、证据及限制见 [COMPATIBILITY.md](../../COMPATIBILITY.md)。本说明不代表发生过云端构建，也不承诺自动重新发布本版本。
